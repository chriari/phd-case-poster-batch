# 模板与品牌规则(2026-08 年轻互联网版)

> 逐节点精确构建参数(施工图)见 [references/build-spec.md](references/build-spec.md),构建时必须按它填每个节点的坐标/内边距/字号/颜色,不要凭感觉。

本规范替代旧版「色块+贴字」模板(旧模板图已从仓库移除)。
海报在 **Ardot 画布**上制作:画布 1080×1440,制作完成后导出 PNG,按原文件名保存。

## 制作方式(稳定可复现,重要)

- 每次批次**新建一个 Ardot 设计文件**,不要复用出现渲染问题的旧文件
- **每张海报用 Insert(I) 从零构建**,严禁 Copy 样板 frame(会导致渲染内容互相串,数据对但渲染错)
- 构建顺序:顶层 frame → Hero → 地区行 → 大标题 → 学校胶囊(临时)→ 正文卡片 → **学校胶囊(正式,在卡片 z 之后)** → 水印 → slogan
- ⚠️ **学校胶囊必须 z 顺序在 ContentCard 之上**——否则卡片会盖住胶囊。推荐做法:先把 SchoolChip 临时插入 Hero 内构建,等 ContentCard 完成后,用 `M` 把 SchoolChip 移动到 demo 顶层且 index 在 ContentCard 之后(确保 z 在 Card 之上)。在导出前用 `capture_screenshot` 校验一遍,如果发现胶囊被遮,立刻调整 z 顺序。
- 全部建完后再导出:export_nodes scale=1 得 1080×1440 PNG
- 校验:像素对比同内容参照差异应 <5%,不同内容参照差异应 >8%(如昆士兰 vs 样板 ≈1.5%,vs Heriot ≈10%)
- `.jpg` 原文件:导出 PNG 后需用 PIL 转成真 JPEG,禁止把 PNG 字节存成 .jpg

## 版式结构(从上到下)

1. **Hero 主视觉**(高 540px,全宽 1080,对角渐变,无圆角)
   - 顶部:地区标签行 —— 白色小圆点(16px)+ 地区文字(40px Bold 白)
   - 中部:大标题(110~116px Bold 白,带 6px 柔阴影,如 `导师回复套磁啦!`)
   - 底部:学校胶囊 —— 白底、圆角 999、含彩色小圆点(22px)+ 学校文字(52px Bold 深色)
2. **悬浮正文卡片**(x 60, y 470, 宽 960, 圆角 32, 白底, 软投影 y18 r44)
   - Dear 行(34px,含马赛克块)
   - 正文(34px 深灰 #333)
   - 红框关键句组(红框 4px + 浅粉底 #FFF6F6,圆角 14)
   - `Best,`(34px)
   - 签名马赛克块
3. **底部**(卡片下方):slogan(30px 浅灰)+ 三色小圆点组(绿/黄/青,各 14px)
4. **整幅背景**:浅色对角渐变(同色系),Hero 的深色向下自然化开,避免硬边界

## 三套配色(对角渐变,左上→右下)

| 类型 | Hero 渐变(0 → 0.5 → 1) | 学校文字 | 背景浅渐变 | 胶囊圆点 |
|---|---|---|---|---|
| 普通回复(绿) | `#144E3B → #1A8A66 → #26A380` | `#0B4A38` | `#E9F4EE → #FBFDFC` | 亮黄 `#FFC53D` |
| 面试邀请(紫) | `#42267F → #573BA1 → #7554C7` | `#5035A8` | `#EFEAF8 → #FAF8FD` | 亮黄 `#FFC53D` |
| Offer(蓝) | `#143D70 → #1F5E92 → #2B80BF` | `#14406E` | `#E8F1FA → #F8FBFD` | 亮黄 `#FFC53D` |

- Hero 渐变使用 `GRADIENT_LINEAR`,`gradientTransform: [[0.707, 0.707, 0], [-0.707, 0.707, 0]]`
- 白色标题在三种背景上均清晰,无需改色

## 字体

- 中文:`Sarasa Gothic SC`(Bold 标题 / Regular 正文)
- 数字/英文:`Inter`
- 字号全部 ≥ 34px:标题 110-116、地区 40、学校 52、正文 34、slogan 30
- ⚠️ 依赖 Ardot 环境内置这两个字体。**换机器/同事首跑时,先只做 1 张测试图**,确认标题/正文渲染与预期一致(若环境缺字体,文字会 fallback 成其他字体,需先解决字体再批量)。

## 水印

- 白色正文卡片区域铺 **2×2 网格**「乐意轻学」水印(共 4 个)
- fontSize 84、旋转 -12°、透明度 4.5%、深灰 `#2A2A2A`
- 参考位置:两行两列(x 180 / 640,y 600 / 1010)

## 脱敏(马赛克)

- 学生、导师、第三方姓名、邮箱、电话、ID、申请号、账号、签名等 → 灰白圆角矩形块
- 块色 `#C7C7C7`,高约 38px,圆角 6,不留任何文字/括号/首字母残留
- 学生 RP 具体题目、具体研究方向、可识别课题 → 打码;宽泛学科方向可保留
- 导师具体研究方向、命名理论/模型、项目、基金、实验室、中心、课题组、数据集、独特课题 → 打码
- 任何可反向定位导师的独特职务、机构组合、链接、签名 → 打码;不确定一律打码
- 不得写"姓名已隐藏"等替代文字

## 红框(圈重点)

- 用 4px 红框 `#FF4757` 圈出:Offer 结果、面试邀请、导师积极意向、材料要求、申请窗口、入学时间、奖学金或指导关系状态
- 红框内加浅粉底色 `#FFF6F6`,圆角 14
- 红框不得遮挡正文

## 标题与地区

- 地区标签:`中外合办-PHD`(中外合办院校);其他写 `地区-PHD`(如 澳洲-PHD、英国-PHD、香港-PHD)
- 大标题:普通回复 → `导师回复套磁啦!`;面试邀请 → `导师邀请面试啦!`;Offer → `博士OFFER来啦!`
- 学校标签:`学校中文名｜QS数字`(非美校)/ `学校中文名｜USNEWS数字`(美校);排名 200 名内展示,否则只写中文名;不写年份、"世界大学排名"、"第"

## 底部固定文案

`@ 乐意轻学   # 提供去中介化的半DIY博士留学服务`(30px,浅灰 #8A8A8A)
